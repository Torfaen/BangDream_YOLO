# REQ-20260427-m0-env

## 背景/目标

本阶段对应主计划 `m0_env`，目标是确认本机环境能支撑后续 BangDream YOLO 自动打歌项目：

- Python 环境可用
- MuMu Player 12 可定位
- ADB 可连接模拟器
- `nemu_ipc` 所需 DLL 可找到
- 后续能进入截图、minitouch、多指触控验证阶段

## 范围

本阶段做：

- 创建基础项目结构
- 创建 `requirements.txt`
- 创建 README 骨架与免责声明
- 创建基础配置文件
- 提供环境检查脚本

本阶段不做：

- 不实现 YOLO 推理
- 不实现 nemu_ipc 截图主逻辑
- 不实现 minitouch 多指控制
- 不训练模型
- 不做自动打歌闭环

## 技术细节

### Python

- 推荐 Python 版本：3.11
- 使用本地虚拟环境：`.venv`
- 依赖初版：
  - `ultralytics`
  - `opencv-python`
  - `numpy`
  - `adbutils`
  - `pyyaml`
  - `loguru`

### MuMu Player 12

已确认（本机）：

- **MuMu 安装根目录**（`nemu_folder`，供 `nemu_ipc` 拼接 DLL 路径；**不要**只填到 `nx_device`）：`C:\Program Files\Netease\MuMu`
- **ADB serial**（MuMu 默认端口）：`127.0.0.1:16384`
- **MuMu 实例 ID**：`0`（与端口 16384 对应常见映射；若多开实例以 MuMu 管理界面为准）
- **`external_renderer_ipc.dll` 本机实测路径**：`C:\Program Files\Netease\MuMu\nx_device\12.0\shell\sdk\external_renderer_ipc.dll`

实现侧应依次尝试（相对安装根目录）：

- `shell/sdk/external_renderer_ipc.dll`
- `nx_device/12.0/shell/sdk/external_renderer_ipc.dll`

### 配置文件

计划创建：

- `src/bangdream_yolo/config.py`

包含：

- `mumu_path`
- `instance_id`
- `display_id`
- `adb_serial`
- `screen_width`
- `screen_height`
- `log_level`

### 验证脚本

计划创建：

- `src/bangdream_yolo/tools/check_env.py`

检查项：

- Python 版本
- 关键依赖 import
- ADB 是否可执行
- 是否能列出设备
- MuMu 路径是否存在
- `external_renderer_ipc.dll` 是否存在

## 验收标准

- `python -m bangdream_yolo.tools.check_env` 能运行
- 能输出清晰的环境检查结果
- 依赖缺失、ADB 未连接、MuMu 路径错误时有明确错误提示
- 不要求本阶段完成截图或点击

## 风险与回滚

风险：

- MuMu 安装路径因版本不同而变化
- ADB serial 可能因多模拟器/多设备而不唯一
- `external_renderer_ipc.dll` 在 MuMu 国际版或旧版本中不可用

回滚：

- 本阶段只新增项目骨架与文档，无侵入式改动
- 如路径设计不合适，可直接调整配置文件字段
